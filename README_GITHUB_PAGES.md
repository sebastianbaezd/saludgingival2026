# Publicar este sitio en GitHub Pages

## Qué contiene esta carpeta
- `index.html` → formulario del test
- `resultado.html` → pantalla separada de resultado
- `assets/` → ilustraciones e iconos
- `.nojekyll` → evita procesamiento innecesario de GitHub Pages

## Cómo publicarlo desde la web de GitHub
1. Entre a GitHub y cree un repositorio nuevo.
2. Déjelo como **Public**.
3. Entre al repositorio y elija **Add file** > **Upload files**.
4. Suba **todo el contenido de esta carpeta**.
5. Haga clic en **Commit changes**.
6. Entre a **Settings** > **Pages**.
7. En **Build and deployment**, en **Source**, elija **Deploy from a branch**.
8. En **Branch**, deje **main** y carpeta **/** (root).
9. Guarde los cambios.
10. Espere unos minutos hasta que GitHub le muestre la URL pública.

## Reemplazar imágenes por ilustraciones propias
Puede reemplazar estos archivos sin tocar el resto del sitio:
- `assets/risk-low.svg`
- `assets/risk-moderate.svg`
- `assets/risk-high.svg`
- `assets/icon-recommendation.svg`

Mantenga los mismos nombres para que todo siga funcionando.
